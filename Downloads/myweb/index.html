My Projects & Skills

Here are three things I have learned and built so far:

Personal Portfolio Website

Built a multi-section responsive portfolio using semantic HTML5, external CSS, and Flexbox/Grid layout.

I learned how to structure pages with header, nav, main, section and footer; how to link external stylesheets; and how to make content readable at narrow widths.

JavaScript Form Validation

Created a contact form with client-side validation using JavaScript and DOM manipulation.

I learned event.preventDefault(), regular expressions for email checking, trimming whitespace, and updating the DOM with textContent.

Responsive Media Gallery

Designed a photo gallery and media section that scales cleanly on phones and desktops.

I learned CSS Grid auto-fit, object-fit for images, and the viewport meta tag for mobile responsiveness.
